# Винная подборка

Приложение показывает качество модели на тестовой выборке и оценивает отдельные вина и партии. В боковой панели один порог отбора для всех прогнозов. Вино попадает в подборку, если его вероятность не ниже текущего порога.

## Локальный запуск

Откройте терминал в каталоге `wine_app`. Используйте Python 3.11. Зависимости проверены с Python 3.11.15.

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Из корня worktree можно запустить `python -m streamlit run homework/hw_3/wine_app/app.py` в том же окружении. Для применения темы запускайте Streamlit из каталога `wine_app`.

## Модель и данные

`model.joblib`, `config.json` и `test.csv` получены из ячейки экспорта ноутбука `KonovalovIA_HW3_MMDA.ipynb`. Чтобы обновить файлы, выполните ноутбук в окружении Python 3.11 с зависимостями из ноутбука. При первом запуске ползунок берёт порог из `config.json`. По умолчанию тест содержит 1 596 вин, precision составляет 41,1%, recall — 73,6%, F1 — 52,7%.

`test.csv` содержит тестовую выборку из набора Wine Quality, Cortez, P., Cerdeira, A., Almeida, F., Matos, T. и Reis, J. (2009). Материалы курса объединяют данные по красным и белым винам и преобразуют оценку от 7 баллов в `target=1`. Ноутбук удаляет полные дубликаты и выделяет тестовую выборку. [Датасет UCI](https://doi.org/10.24432/C56S3T) · [Лицензия CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

## CSV для пакетного прогноза

Загрузите файл UTF-8 с запятой и заголовком. Порядок столбцов произвольный. Все 12 полей должны содержать конечные числовые значения. `is_red` равен `0` для белого вина и `1` для красного.

```csv
fixed_acidity,volatile_acidity,citric_acid,residual_sugar,chlorides,free_sulfur_dioxide,total_sulfur_dioxide,density,pH,sulphates,alcohol,is_red
```

Скачиваемый `wine_predictions.csv` сохраняет исходный порядок строк и добавляет `probability_good` (от 0 до 1) и `recommendation`.

## Кэширование

`st.cache_resource` хранит один объект модели для повторных запусков и пользовательских сессий. Прямой вызов `joblib.load` заново читал бы файл при каждом взаимодействии со Streamlit. `st.cache_data` хранит тестовую таблицу и рассчитанные вероятности. При движении ползунка меняются решения и метрики. Загруженные пользователем партии хранятся в его сессии.
